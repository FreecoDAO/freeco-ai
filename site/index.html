Open source · Self-hosted

Agents that keep working
when you close the laptop.

FreEco.ai is an operating system for autonomous agents. Not a chat window — a system that runs your CRM, your books, your calls and your projects on schedules, with budgets and approval gates, on hardware you own. 

curl -fsSL https://raw.githubusercontent.com/FreecoDAO/freeco-ai/main/scripts/install.sh | sh
openfang init && openfang start

One binary. Dashboard at localhost:4200.

A back office, not a chatbot

Most agent tools stop when the tab closes. FreEco.ai ships the parts a business actually runs on, wired together through MCP so agents can use them directly rather than through screenshots and copy-paste.

CRM

Twenty, self-hosted. Contacts, deals and pipeline that agents can read and update as MCP tools.

Accounting

Akaunting, self-hosted. Invoices and ledger, so an agent can raise a bill rather than draft an email about one.

Real-time voice

dograh, MCP-native. Live calls with barge-in and telephony for outreach and support.

Companies & projects

Org structure as a first-class concept: role hierarchy, teams, calendars, tasks, documents and knowledge.

Isolated Linux sandbox

Agent code runs in a throwaway container with no network and every capability dropped — never on your machine.

Budgets & approval gates

Spend caps per agent, and allow-once / allow-always / deny answered inline in the chat.

What FreEco.ai does not do

A table that only flatters its author is worth nothing. The honest limits:

  • Frontier reasoning still comes from a frontier model. Local Gemma 4 is free and private, and it is not Opus. Hard tasks route to a cloud model through your own key.
  • Local models need a real GPU. Without a discrete GPU one agent turn can take about an hour, so local inference is off by default on such machines and the reason is stated plainly in the interface.
  • The business services are integrations, not rewrites. Twenty and Akaunting are excellent existing products, run as containers alongside.
  • Self-hosting is work. A server, DNS and TLS are your responsibility in a way a SaaS signup is not.
  • Younger than the incumbents, with the rough edges that implies.

Run the whole stack

FreEco.ai with CRM, accounting and voice, in one command. This is the demo environment and the base for FreEco.ai as a hosted service. 

git clone https://github.com/FreecoDAO/freeco-ai
cd freeco-ai/deploy/demo
cp .env.example .env      # fill in the secrets
docker compose up -d
:4200FreEco.ai dashboard
:3200Twenty CRM
:8080Akaunting
:8000dograh voice

Hosting: shared plans will not run this

The stack needs a VPS or dedicated server with root — 8 GB RAM minimum, 16 GB comfortable. Shared hosting has no Docker daemon, no root, and kills long-running processes, and every part of this is a container.

This page is different. It is static HTML with no build step and no external requests, so it runs anywhere — including shared hosting. Upload it and point the domain at it; the app stack can live on a separate server, since DNS is independent of hosting.
